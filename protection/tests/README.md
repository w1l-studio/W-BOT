# اختبار نظام الحماية

من مجلد المشروع شغّل:

```bash
node protection/tests/run.js
```

الاختبار يتحقق من:
- أن وضع التشغيل الافتراضي هو المراقبة فقط وأن Anti-Link متوقف افتراضيًا.
- تطبيع الرسائل وفحص قائمة السماح للروابط.
- عتبة Anti-Nuke ومنع تكرار البلاغات خلال التهدئة.
- قراءة/حفظ/حذف إعدادات السيرفر.
- حفظ سجل الحوادث وقراءته بعد إنشاء خدمة تخزين جديدة.

الاختبار محلي ولا يتصل بديسكورد. يجب إجراء اختبار منفصل في سيرفر تجريبي لصلاحيات البوت، الأحداث الفعلية، وضع الطوارئ، وترتيب الرتب.
